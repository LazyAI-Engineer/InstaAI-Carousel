# InstaAI Carousel Generator

> Turn an AI Engineering topic into a structured, visually designed 7-slide Instagram carousel.

**InstaAI** is an AI-powered carousel generator built as part of my **Lazy AI Engineer** journey — learning AI Engineering from zero by building real projects and sharing what I learn.

Enter a topic such as:

```text
What is RAG?
```

InstaAI generates the educational content, validates its structure, creates matching technical visuals, and renders **7 separate 1080 × 1350 Instagram carousel images**.

---

## ✨ What It Does

InstaAI converts a single topic into a complete educational carousel:

```text
Topic
  ↓
SenseNova LLM
  ↓
7-Slide Structured JSON
  ↓
Content + Visual Validation
  ↓
Adaptive HTML / CSS / SVG Renderer
  ↓
Playwright + Chromium
  ↓
7 Separate 1080 × 1350 PNG Slides
```

The generated carousel is designed for beginner-friendly AI Engineering content.

---

## 🖼️ Carousel Structure

Every carousel contains exactly **7 slides**:

| Slide | Purpose |
|---|---|
| 1 | Hook |
| 2 | Problem / Why It Matters |
| 3 | Core Concept |
| 4 | How It Works |
| 5 | Practical Example |
| 6 | Key Insight / Comparison |
| 7 | Takeaway |

This helps prevent the AI from generating seven disconnected pieces of information.

---

## 🎨 Visual System

InstaAI supports multiple visual layouts depending on the information being explained:

- `hero` — central concept or relationship
- `comparison` — compare two ideas
- `flowchart` — sequential workflow
- `process` — start → steps → result
- `tools` — concept connected to tools or capabilities
- `cards` — categories, examples, components, or use cases
- `equation` — components combining into a result

The AI does not generate the final slide images directly.

Instead, it generates structured `visual_data`, which is passed into a deterministic renderer.

This makes the carousel design more consistent and predictable.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/LazyAI-Engineer/InstaAI-Carousel.git
cd InstaAI-Carousel
```

### 2. Install Python dependencies

```bash
pip install -r ./InstaAI/requirements.txt
```

### 3. Install Chromium for Playwright

```bash
playwright install chromium
```

On some Linux environments, additional Chromium system dependencies may also be required.

### 4. Configure the API key

Inside the `InstaAI` directory, create:

```text
.env
```

Use `.env.example` as the template:

```env
SENSENOVA_API_KEY=your_sensenova_api_key_here
```

Never commit your real `.env` file or API key.

### 5. Run InstaAI

From the repository root:

```bash
python ./InstaAI/app.py
```

Enter a topic:

```text
What is a Vector Database?
```

InstaAI will generate and validate the content before rendering the carousel.

## 🔐 Security

API credentials are stored locally using environment variables.

The real `.env` file is excluded through `.gitignore`.

The repository includes only:

```text
.env.example
```

Never place a real API key directly inside the source code.

If a key is accidentally committed, revoke/rotate the key immediately because removing it from the latest version does not automatically remove it from Git history.

## ⚠️ Current Limitations

This is a learning project and an early version of InstaAI.

Current limitations include:

- Generated content should still be reviewed before publishing.
- LLM output can vary between generations.
- Rendering requires Chromium through Playwright.
- SenseNova API access is required.
- The project currently uses a terminal interface.
- Instagram publishing is manual.
- There is no hosted web interface yet.
